Eliminar a tua conta Series Organizer+

Última atualização: 6 de outubro de 2026

Series Organizer+ é desenvolvido pela LastDay Software. Esta página é o processo público na Web para solicitar a eliminação de uma conta cloud Series Organizer+.

O que é eliminado

  • A tua conta de autenticação Supabase do Series Organizer+
  • Os snapshots de Cloud Backup Series Organizer+ associados
  • Os registos cloud de sincronização e o histórico de alterações/operações associados

Os Cloud Backups e os dados de sincronização são eliminados com a conta de autenticação associada. Isto inclui o conteúdo da Biblioteca e os dados de acompanhamento guardados na cloud.

O que não é eliminado

Eliminar a tua conta Series Organizer+ não elimina a tua Conta Google.

Eliminar a conta cloud não apaga remotamente os dados dos teus dispositivos. A eliminação na aplicação permite manter os dados do perfil associado como dados de convidado ou eliminar os dados locais desse perfil no dispositivo atual. Outros dispositivos e perfis de convidado não relacionados não são apagados. As cópias locais permanecem até as removeres pela aplicação, pelos controlos de armazenamento do dispositivo ou pela desinstalação.

O Firebase Analytics opcional utiliza um identificador da instância da aplicação, não o identificador da tua conta cloud. Eliminar a conta cloud não elimina, por si só, analytics recolhidos anteriormente. Para questões de privacidade ou um pedido separado de eliminação de dados, contacta privacy@seriesorganizer.com. Nunca envies palavras-passe nem tokens de autenticação.

Eliminar a conta na aplicação

Com sessão iniciada, abre Perfil > Conta e sincronização e escolhe Eliminar conta. Revê se pretendes manter os dados associados deste dispositivo como dados de convidado ou eliminá-los e confirma a eliminação permanente. A conta cloud é eliminada primeiro; uma falha remota não elimina a Biblioteca local. Se a aplicação pedir que concluas a limpeza local depois, utiliza a ação de nova tentativa para concluir a opção já escolhida.

Solicitar eliminação sem a aplicação

Envia um email a partir do endereço Google utilizado para iniciar sessão no Series Organizer+ para privacy@seriesorganizer.com com o assunto “Pedido de eliminação da conta Series Organizer+”. Indica claramente que pretendes eliminar a conta cloud Series Organizer+, os respetivos Cloud Backups e dados de sincronização. Não precisas de instalar a aplicação nem de iniciar sessão neste site.

Verificação da conta

Enviar o pedido a partir do endereço Google utilizado no Series Organizer+ ajuda a verificar qual a conta que deve ser removida. Se não conseguires enviar a partir desse endereço, contacta o suporte e a LastDay Software solicitará apenas a informação limitada e não confidencial necessária para verificar a titularidade da conta antes da eliminação.

Nunca envies palavras-passe ou tokens de autenticação. A LastDay Software nunca solicitará a tua palavra-passe Google, token de acesso Supabase, refresh token ou outra credencial privada de autenticação num pedido de eliminação.

Prazo de processamento

Os pedidos por email verificados serão concluídos no prazo de 30 dias de calendário. O requerente receberá confirmação no endereço de email utilizado no pedido após a conta, os Cloud Backups e os dados de sincronização associados terem sido eliminados.

Exceções de retenção

Se for necessário conservar informação específica devido a uma obrigação legal aplicável, necessidade de segurança ou requisito de prevenção de abuso, essa informação será conservada apenas para a finalidade e período necessários. A correspondência relativa ao pedido de eliminação poderá ser conservada pelo período razoavelmente necessário para documentar e concluir o pedido.

Utilização local-first após a eliminação

Series Organizer+ não requer uma conta para a utilização normal da Biblioteca local. Por isso, eliminar a conta cloud não impede a utilização local da aplicação.
