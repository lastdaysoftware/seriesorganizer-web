SERIES ORGANIZER+ · WINDOWS DESKTOP AND CHROME

Install and pair the Browser Watching extension

The recommended way to install Series Organizer+ Browser Watching is through the Chrome Web Store. You need Chrome and Series Organizer+ Desktop on the same Windows computer. Installing Desktop does not install or enable the extension automatically.

In this guide
  • Install from the Chrome Web Store
  • Switch from the bundled copy
  • Store updates
  • Manual installation fallback
  • Update a manual copy

Install from the Chrome Web Store

  1. Install and open Series Organizer+ Desktop.
  2. Open the official Series Organizer+ Browser Watching listing in Chrome on that computer.
  3. Select Add to Chrome, review the permissions and confirm with Add extension.
  4. From Chrome's Extensions menu, pin Series Organizer+ Browser Watching if you want its badge to stay visible.
  5. Follow Set up Browser Watching to enable the Desktop feature and approve local pairing.

The Store version does not need Developer mode or Load unpacked. Installation follows Chrome's official extension instructions. Nothing is marked as seen until you confirm the watch in Desktop.

Switch from the bundled copy

If you previously used Load unpacked, switch to the Store version rather than running both copies.

  1. Note your existing extension options. Open chrome://extensions and remove the manually loaded Series Organizer+ Browser Watching copy.
  2. Install from the Chrome Web Store using the steps above.
  3. Connect the Store copy to Desktop and approve pairing again. Re-select your optional background-check and automatic-send settings; do not assume the old copy's pairing or options carry over.
  4. Refresh streaming tabs that were already open, then send a detected title and check the match in Desktop.

Removing the Chrome extension does not remove your Desktop Library or watch history. Keep only one copy active to avoid duplicate detections or confusing badges.

Store updates

The Store version uses Chrome's extension update mechanism, separately from Desktop MSI updates. After an extension update, refresh already-open streaming pages and check the popup if detection looks stale. A Desktop update does not require loading or reloading the bundled copy when you use the Store version.

Manual installation fallback

The Windows installer still supplies an unpacked copy for manual installation. Use this only as an alternative to the Store copy, not alongside it.

  1. Install and open Series Organizer+ Desktop.

  2. In Chrome, enter chrome://extensions in the address bar.

  3. Turn on Developer mode.

  4. Select Load unpacked and choose the installed extension folder:

    <your installation folder>\app\resources\browser-extension\watch-detection-pilot

    For a new installation using the default location, this is %LOCALAPPDATA%\LastdaySoftware\SeriesOrganizerPlus\app\resources\browser-extension\watch-detection-pilot. If you chose a different installation folder, use that folder instead. Older installations may still use %LOCALAPPDATA%\Series Organizer Plus. Select the folder containing manifest.json, not its parent. If the chooser does not expand an environment variable, open the location in File Explorer first.

  5. From Chrome's Extensions menu, pin Series Organizer+ Browser Watching if you want its badge to remain visible.

  6. Follow Set up Browser Watching to enable the SO+ Desktop feature and approve the connection.

These steps follow Chrome's official unpacked-extension instructions.

Update a manually installed copy

  1. Install the newer Desktop MSI.
  2. Return to chrome://extensions.
  3. Select Reload on the extension you loaded from the installed folder.
  4. Refresh any streaming pages that were already open.
  5. Open the popup and check Desktop pairing.

Do not assume that updating SO+ Desktop reloads Chrome's unpacked extension automatically. Chrome's reload guidance requires a host-page refresh after content-script changes.

If you changed the Desktop installation folder, Chrome may still point to the older copy. Note your extension options, remove that old extension from Chrome, load the new installed folder and pair again. Removing the Chrome extension does not remove your Desktop Library or watch history.
