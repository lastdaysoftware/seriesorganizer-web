ANDROID & WINDOWS HELP

Library, sync and cloud backups

Three actions, three different jobs. Library updates download title information; account sync exchanges supported changes between devices; Cloud Backup saves a recovery copy.

Controls use their English names here. Keep both apps updated before exchanging newer backups.

Your Library and filters

Add a movie or TV show through Discover, then open Library or Up Next to track it. The Library stays on your device and does not require an account. Favorites and Archive organize your own titles; removing a Library membership does not erase its recorded watch history.

  • All / TV Shows / Movies: choose one media category.
  • Up Next and Favorites: narrow the current results. Combined filters must all match.
  • Archive: switch to archived titles rather than mixing them into the normal list.
  • Any day / Today / Tomorrow / This Week: choose one date filter using available episode air dates or movie release dates. A title with no known date may not match a date filter.
  • Your services: match your own Library against the region and services chosen in Profile. Availability may be checked when you enable it; this never searches for extra titles to add.
  • Detailed / Grid and Search: change how results look or find a title. Clear filters returns to the default selection.

Use the card's Start watching or Mark watched action only when you intend to record that watch. Open the title to inspect the episode or movie first if unsure. Browser Watching has a separate review and setup guide.

Update title information

Adding a title tries to download its complete information. If that download fails, the title stays in your Library and you can retry. After sync or restore, titles may appear before this device finishes downloading seasons and episodes. Missing information does not mean you are caught up.

Use the Library update or its Retry action to finish missing information. A manual full update includes archived titles. An interrupted update can reuse fully saved titles without resetting recorded watches.

Sync across devices

  1. Sign in with the same account on both devices and check the active local profile. Signing in does not silently replace your guest Library.
  2. Open Profile → Account & Sync → Sync now. If initial setup asks for a cloud backup, make it on the device whose data you intend to save.
  3. If differences need review, choose this device's value or the cloud value deliberately. Check the title and field, not just the overall totals.
  4. Apply completed choices, then use Sync now again when prompted. Continue if more changes remain.
  5. Sync the other device and check the same titles or episodes.

Sync exchanges supported Library membership, tracking and portable preferences, not TMDB metadata, artwork, device-specific settings or the complete Viewing Activity history. Resolving a review and uploading the resulting changes are separate steps.

Sync preserves positive watch progress against a zero count. Mark unseen can therefore work locally but become watched again after syncing with another device that still has positive progress. Competing positive counts or uncertain differences can still require review.

Enable automatic account sync

First complete a successful manual Sync now on each device. Then choose Enabled or Disabled in its automatic account-sync settings. This switch stays local to that device.

When enabled, grouped edits can trigger a check after a short delay, with a 20-minute safety interval. Desktop checks while open, including in the tray; Android checks while the app is in the foreground. Closing Desktop or leaving the Android app stops this automatic account-sync loop.

Temporary failures retry with a waiting period. Manual Sync now can bypass that wait, and a successful manual sync resets it. Pending restore/setup/review choices must still be handled; automation never silently resolves conflicts. Account sync does not refresh TMDB information and is not an automatic backup.

Create a backup or restore

Back up now saves an immutable recovery snapshot of the active linked profile's Library, tracking, Viewing Activity and portable preferences. It excludes downloaded metadata, artwork and device-only settings. Backups are manual and remain separate from sync.

Use backup history and the device/cloud totals as a quick check. If another device saved a newer backup, confirm only if you intend this device's snapshot to become the newest recovery copy; backing up does not merge changes held only on the other device.

An offered restore is an explicit choice for an account without an existing linked local profile. It preserves the guest Library; an existing linked profile is reopened, not silently replaced. Title information downloads separately afterwards.

If a restore is interrupted, retry the same selected backup. If it is no longer available, the app offers cancellation of the unfinished restore so you can choose another. This does not delete existing Library data or cloud backups. Do not uninstall your main app or clear its data to troubleshoot.

Settings across devices

Portable settings include languages, theme/presentation, Library/Up Next options, content preferences, streaming region and services. If initial settings differ, choose Use this device's settings or Use cloud settings. Cancel leaves both sides unchanged; Review settings reopens the choice.

Notifications/permissions, analytics consent, schedules, pairing, local folders and window/tray settings remain local. Changing settings does not itself resolve Library conflicts, and syncing is not an instant push to a closed app.

When something fails

Check the active profile, filters and the exact operation's status. A successful backup does not prove that sync or metadata downloads finished. If you see a capacity limit, keep your data and report the displayed counts rather than deleting history to make it fit.

For further help, contact support with the app version, device and operation you tried. Review diagnostic logs and screenshots before sharing; never send passwords, tokens or signing keys.
